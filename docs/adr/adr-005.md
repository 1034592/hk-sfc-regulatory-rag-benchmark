# ADR-005　评测集统一使用英文

## 背景
语料为香港证监会英文法规原文（《持牌人操守准则》《基金经理操守准则》）。
评测需对比多语种模型 bge-m3 与英文单语模型 bge-small-en-v1.5。

## 决策
100 题评测集全部以英文撰写。

## 理由
bge-small-en-v1.5 为英文单语模型。若以中文出题，该档成绩将因语种不匹配而系统性偏低，
得到的差距无法区分「模型容量差异」与「语种覆盖差异」，使双模对比结论不成立。
统一英文可将变量收敛为检索能力本身。香港持牌法团合规人员查阅 SFC 条文亦以英文为主，
英文查询符合真实使用场景。

## 后果
本基准不反映跨语种检索能力。中文查询场景下 bge-m3 的多语种优势未被测量，
如需评估应另建中英对照评测集，并作为独立实验报告。
