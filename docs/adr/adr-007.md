# ADR-007　条款级而非切块级的命中判定

## 背景
一个法规条款（如 Schedule 4、17.6 Due diligence）因篇幅较长会被切分为多个切块。
评测集的 gold 标注为条款编号，而非具体切块。

## 决策
检索结果先由切块排名折叠为条款排名（同一 clause_id 取其最佳名次，去重保序），
再计算 Recall@k / Hit@k / MRR / NDCG。

## 理由
若按切块判定，同一条款的多个切块会重复占据排名前列，
使 Recall@5 虚高且无法反映「是否找到了正确条款」这一真实业务目标。
合规人员的诉求是定位到条款，而非定位到某个切块。

## 后果
切块粒度的差异（长条款切得更碎）不再直接影响指标，
各配置在同一折叠规则下可比。副作用是无法评估切块内部的定位精度，
该维度需另行以答案片段级标注评测。
